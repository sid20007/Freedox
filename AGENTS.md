## Rules & Guidelines
1. **Strict Scope Control:** Keep scope strictly to what is requested. Do not add extra unrequested features.
2. **Frequent Git Commits:** Commit code after each working feature with clear, descriptive commit messages.
3. **Plan First:** State a brief implementation plan before making major changes.
4. **Autonomous Problem Solving:** Make reasonable technical assumptions instead of asking questions unless genuinely blocked.
5. **Beginner-Friendly Explanations:** Explain concepts and implementations simply and clearly, keeping in mind that the user is a beginner.
